# 提示模板

小瑞助手 3.5.0 将原有的固定破甲提示升级为原生提示模板模块。模板只参与模型请求的文本组装，不修改 Android 工具授权。

## 使用

在「设置 → 提示模板」中新建或编辑模板，填写名称和提示正文。可以选择默认模板，并为某个服务商或某个具体模型绑定模板。模型绑定使用服务商 ID 与实际请求的模型名称，因此不同服务商的同名模型不会互相影响。

在智能助手中切换到「破甲」，再选择本次会话的模板。「自动」依次使用模型绑定、服务商绑定和默认模板；「不使用」明确关闭本次会话的模板。普通模式不使用模板。新会话会保留发送第一条消息之前的草稿选择。

角色扮演默认不使用助手模板，单独选择模板后才添加到该角色会话。角色设定、世界书、剧情记忆与工具指令继续由原有运行时组装。

每次生成启动时冻结模板正文。修改模板会从下一次生成生效。已禁用、已删除或无效的显式选择不会悄悄替换成其他模板。

## 导入与备份

模板页可导出独立 JSON 文件，并在导入时预览、合并或替换。独立文件包含模板、模型/服务商绑定和默认项，不包含私人会话 ID。合并会更新相同 ID 的模板和相同服务商/模型的绑定，保留其他本地项目；替换会清理旧绑定。

完整数据备份保留模板及会话选择。旧版本备份没有模板字段时，保留设备上的模板。导入会验证格式标记、版本、大小、重复 ID 与引用关系，无效文件不会写入存储。

## 来源

提示模板和规则管理的功能设计参考 **dsh-purge 1.1.71**，原作者 **小杨 / YuJunZhiXue**，来源：<https://github.com/YuJunZhiXue/dsh-purge>。

此模块为小瑞助手的 Kotlin 原生实现，没有打包或执行 dsh-purge 的 Node.js/Cordis 插件，没有复制其加密默认提示词，也没有包含 DSH 桌面宿主补丁。内置「直接交流」模板沿用小瑞助手此前已有的提示文本。模板效果取决于所选模型与服务端策略。
